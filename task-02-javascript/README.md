Реализованная функциональность

Каталог товаров:

- карточки товаров создаются динамически средствами JavaScript
- данные товаров хранятся в массиве объектов
- реализован поиск по названию товара
- реализована фильтрация по категории
- реализована фильтрация по типу питомца
- реализована сортировка по цене и названию
- отображается количество найденных товаров

Избранное:

- товар можно добавить в избранное
- товар можно удалить из избранного
- страница избранного формируется динамически
- данные избранного сохраняются в localStorage

Корзина:

- товар можно добавить в корзину из каталога и избранного
- реализовано изменение количества товара
- товар можно удалить из корзины
- итоговая сумма пересчитывается автоматически
- данные корзины сохраняются в localStorage

Подарочный сертификат:

Реализована форма оформления подарочного сертификата.

Пользователь может указать:

- сумму сертификата
- имя получателя
- телефон или e-mail
- дату отправки
- время отправки
