ДЗ №3. Браузерный API

Используемые Browser API

1. Web Storage API - localStorage
localStorage уже использовался во 2 дз для сохранения пользовательского состояния между перезагрузками страницы.
С помощью Web Storage API сохраняются
- товары, добавленные в избранное
- товары, добавленные в корзину
- количество товаров в корзине

Используются методы:
- localStorage.getItem()
- localStorage.setItem()
Данные сохраняются в формате JSON с помощью JSON.stringify() и восстанавливаются с помощью JSON.parse()

2. В рамках ДЗ №3 дополнительно был интегрирован Web Speech API - SpeechRecognition.

Пользователь может нажать на кнопку микрофона в строке поиска каталога и произнести поисковый запрос голосом.
Например:
- корм для кошек
- корм для собак
- игрушка для кошек

После успешного распознавания речи текст автоматически появляется в строке поиска, а каталог фильтруется по полученному запросу.

Почему выбран SpeechRecognition:
Голосовой поиск упрощает взаимодействие с каталогом и позволяет искать товары без ручного ввода текста. При этом обычный текстовый поиск остается доступным, поэтому приложение продолжает работать даже в браузерах без поддержки голосового распознавания.
